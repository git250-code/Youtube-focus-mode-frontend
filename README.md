# 🎧 YouTube Focus Mode (Chrome Extension)

A distraction-free way to watch **YouTube playlists** — no ads, no recommendations, no sidebar clutter.  
Simply paste a playlist URL and stay focused.

---

## 🚀 Features
- Load any **YouTube playlist** instantly
- Watch videos without sidebar or suggested videos
- Clean, minimalist popup interface
- Backend powered by a YouTube Data API proxy (hosted on Render)
- Safe — API key hidden on the backend

---

## 🧩 Tech Stack
- **Frontend (Extension):** Vanilla JS, HTML, CSS
- **Backend API:** Node.js + Express (deployed on Render)
- **YouTube Data API v3**
